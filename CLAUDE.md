# Instructions de travail — bibliothèque MJ

Le dépôt contient plusieurs jeux et scénarios indépendants. Toujours commencer par le `README.md` racine, puis ouvrir le README du scénario concerné.

## Règles de structure

- Un dossier par jeu, puis un dossier par scénario.
- Pour `En_fanfare_ou_en_catimini`, distinguer explicitement `Episode_1` et `Episode_2`.
- Le dossier `Final` contient le kit de table qui fait autorité.
- Les anciennes variantes restent dans `Versions` ou `Archives` et ne doivent pas être modifiées comme source canonique.
- Ne pas ajouter de projet web sans dossier autonome ni réactiver une configuration GitHub Pages.
- Ne pas versionner `.env`, `.claude`, `__pycache__`, les fichiers audio tiers ou les exports régénérables avec musique embarquée.

## Travail sur un scénario

1. Lire son README et son dossier `Final`.
2. Modifier d’abord la source canonique identifiée.
3. Propager ensuite les changements vers les aides et exports concernés.
4. Vérifier la conduite de table, les transitions, les révélations indispensables et les coupes d’urgence.
5. Mettre à jour le README du scénario si sa structure change.
